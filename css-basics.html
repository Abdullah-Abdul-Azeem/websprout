CSS Basics

CSS changes how a web page looks. Each example shows the CSS rule, the page before, and the page after.

What is CSS?

HTML gives a page its structure. CSS gives it its look: colours, fonts, spacing and borders. A CSS rule has three parts: a selector, a property and a value.

selector { property: value; }

h1 { color: blue; }

CSS can be written inline (style attribute), embedded (in a style element in the head), or external (a .css file linked to every page). This website uses one external file: style.css.

The six properties

  • Colours
  • Backgrounds
  • Fonts
  • Borders
  • Margin
  • Padding

1. Colours

The color property changes the colour of the text. You can use a colour name, a hex code like #ff0000, or rgb / rgba.

2. Backgrounds

background-color changes the colour behind an element. You can also use a picture with background-image.

CSS rule Before (no CSS) After (with the rule)

.yellow-back {
background-color: yellow;
}
This is a paragraph. This is a paragraph.
Remember: color is the text colour; background-color is the colour behind it.

3. Fonts

font-family chooses the font, font-size changes the size and font-weight makes text bold.

CSS rule Before (no CSS) After (with the rule)

.big-font {
font-family: Arial, sans-serif;
font-size: 20px;
font-weight: bold; }
This is a paragraph. This is a paragraph.
Remember: always end the font list with a generic font like sans-serif, in case the first font is missing.

4. Borders

border draws a line around an element. You give the width, the style (solid, dashed, dotted) and the colour.

CSS rule Before (no CSS) After (with the rule)

.blue-border {
border: 3px solid blue;
}

Remember: border: width style colour; in that order.

5. Margin

margin is the space outside the border. It pushes other elements away. The grey boxes show where each paragraph is.

CSS rule Before (no CSS) After (with the rule)

p.with-margin {
margin: 25px;
}

Remember: margin is outside the box, so the grey box does not get bigger.

6. Padding

padding is the space inside the border, between the text and the edge of the box.

CSS rule Before (no CSS) After (with the rule)

p.with-padding {
padding: 20px;
}

Remember: padding is inside the box, so the grey box gets bigger.

Margin or padding?

Margin Padding
Where is it? Outside the border Inside the border
What does it do? Pushes other elements away Makes space around the text inside the box
Does the box get bigger? No Yes
